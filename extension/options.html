本机 Whisper 识别 · 百度翻译 · Edge 字幕叠加

01 / 连接本机

识别服务

运行项目内的 start.ps1，将服务窗口中的连接口令复制到这里。

02 / 文字翻译

百度通用翻译 API

在 百度翻译开放平台 开通通用翻译服务，获取 APP ID 和密钥。保存时会先发送 “Hello” 验证凭据。

百度凭据保存在本机项目目录，扩展不会保存百度密钥。翻译调用将消耗你的百度 API 额度。

03 / 字幕偏好

语言与显示

修改后点击“保存全部设置”，重新启动翻译后生效。

每段会额外参考前后各最多 1 秒语音，优先等待分段收齐。晚到字幕短暂保留以便阅读，下一句到点立即切换；音频识别为空时不会直接清掉已有字幕。

在 YouTube 原播放器观看和听原声。字幕生成后保留 60 秒，按播放时间显示；未来字幕等待到点再显示，缺少缓存时只短暂显示最近播放过的识别结果。已识别为无语音的空隙保持空白。暂停、后退后继续匹配时间。

第一次使用

  1. 运行 setup.ps1 安装依赖，NVIDIA 用户再运行 setup-gpu.ps1，最后运行 start.ps1。
  2. 保存本机口令、百度凭据，点击“准备模型”等待加载完成。
  3. 在 Edge 打开正在进行的 YouTube 直播，播放后先将进度向后拖动一点，再点击扩展的“开始字幕翻译”。

安装或更新扩展后，请刷新 YouTube 页面。能预读多远取决于 YouTube 已下载的音频范围；直播最前沿只能处理已经产生的内容。当前支持 MSE 的 MP4/WebM 独立音轨，无法读取时会显示提示，原声继续播放。原生画中画暂不支持叠加字幕。
